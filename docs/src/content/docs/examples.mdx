The best way to learn DolphJS's conventions is to read a full application, not just isolated snippets. The examples below are open-source, actively maintained, and built to demonstrate the architecture and design principles covered throughout these docs — folder structure, DTO validation, service layering, and more.

## REST API

### DolphStore

A real estate REST API — property listings, reviews, JWT authentication with access/refresh tokens, and payments via Paystack and Flutterwave. Built with TypeORM and PostgreSQL.

DolphStore is the reference implementation for a medium/enterprise-scale DolphJS REST API: environment validation with Joi, request validation with `class-validator`/`class-transformer`, and the upper-level/lower-level service pattern (see [Architecture](/architecture/)) demonstrated through its payments module.

**Stack:** TypeORM · PostgreSQL · JWT · Paystack · Flutterwave

[View on GitHub →](https://github.com/dolphjs/dolphstore-example-rest-app)

:::note
Under active development — modules are being added incrementally. Check the repository for current progress.
:::
