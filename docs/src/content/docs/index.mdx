<CardGrid stagger>

	</Card>
	<Card title="Uncompromised Flexibility" icon="rocket">
		Unlike other enterprise frameworks, DolphJS gives you full access to the Express engine. If it works in Express, it works in Dolph.

	<Card title="Batteries Included" icon="puzzle">
		Native wrappers for GraphQL (Apollo), WebSockets (Socket.io), and deep Auto-wiring for MongoDB and MySQL out of the box.
	</Card>
	<Card title="Rust-Powered CLI" icon="laptop">
		Scaffold apps, generate controllers, and manage components lightning-fast with the brand new Rust-powered CLI.
