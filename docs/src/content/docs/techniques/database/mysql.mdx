DolphJS connects to MySQL through **TypeORM**. Install TypeORM and the MySQL driver:

```bash
npm install typeorm mysql2
```

Then add it to `dolph_config.yaml`:

```yaml
database:
  typeorm:
    options:
      type: mysql
      host: sensitive
      port: 3306
      username: sensitive
      password: sensitive
      database: dolph_db
      synchronize: false
      entities:
        - src/**/*.entity.ts
```

Values set to `sensitive` are read from `SQL_HOST`, `SQL_USER` and `SQL_PASSWORD` in your `.env` file.

Everything else works the same as any other TypeORM database. See the [TypeORM guide](/techniques/database/typeorm).
