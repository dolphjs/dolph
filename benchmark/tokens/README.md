# Token comparison

The same small feature written in DolphJS, NestJS and Express: create an order and fetch one by id, with a validated body, a 404 for a missing order, and a server listening on port 3000.

`node benchmark/token-count.js` counts the tokens in each folder. The website uses these numbers.

This measures the code a developer or a coding agent has to read and write. It doesn't measure a whole agent session, and no agent benchmark exists yet.
